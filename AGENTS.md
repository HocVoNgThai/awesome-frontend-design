# AGENTS.md

This repo is a skill pack, not an app. Work here means editing Markdown skills and two small Node scripts.

- Skills live in `skills/<name>/SKILL.md` with `references/` and `scripts/`. Follow `CONTRIBUTING.md`.
- After editing any skill run `npm run bundle` then `npm test`. Both must pass before a commit.
- No em dash or en dash anywhere. No new dependencies (the CLI and scripts use only Node built-ins).
- Commits: Conventional Commits, author HocVoNgThai, no co-author trailers.
- To use the skills on a frontend task, start from `skills/awesome-frontend-design/SKILL.md`.
